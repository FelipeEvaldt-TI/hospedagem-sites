Hospedagem de Sites

Passos para Hospedagem

  • Criar um repositorio no remoto (Github)
  • Criar repositorio local git init
  • adicionar arquivos em zona de preparação: git add
  • Criar Ponto na história: git commit -m "First commit"
  • Renomear a branch para main: git branch -M main
  • Unificar repositórios: git remote add origin [Endereço do github]
  • enviar o código: git push
